QUESTA CARTELLA CONTIENE LE IMMAGINI DEI GIOCHI
==================================================

Ogni gioco in games.html mostra un'immagine sopra il titolo. Per ora ci sono
delle icone placeholder generate automaticamente (colori diversi per
categoria + iniziali del gioco). Puoi sostituirle con le tue immagini in
qualsiasi momento.

COME SOSTITUIRE UN'IMMAGINE:
1. Prepara la tua immagine (consigliato: circa 200x150 pixel, formato .png
   o .jpg - se usi .jpg ricordati di cambiare anche l'estensione nel file
   games.html, cercando il nome del file corrispondente).
2. Rinominala ESATTAMENTE come il file che vuoi sostituire (vedi elenco
   sotto) e caricala qui dentro, sovrascrivendo quella vecchia.
3. Fatto: non serve modificare nient'altro, games.html la userà subito.
